**Özet:** Türkiye'de tedavi araştıran uluslararası hastalar ve aileleri kendi ana dillerinde (Arapça, İngilizce, Fransızca, Rusça veya Türkçe) arama yapar. Sağlık turizmi şirketlerinin çoğu, yavaş tek dilli siteler veya otomatik çeviri eklentili WordPress temaları yüzünden potansiyel hastalarını aracı pazar yerlerine kaptırır. Doğal Arapça RTL desteğine, derleme zamanı çeviri doğrulamasına ve gizlilik öncelikli iletişim yapısına sahip özel bir Next.js 16 platformu, markayı Google'da kendi adıyla #1 sıraya taşır.

## Uluslararası Hasta Koordinasyon Siteleri Neden Hazır Temalarda Başarısız Olur?

Yurt خارجındaki bir hasta Türkiye'deki organ nakli mevzuatını, onkoloji koordinasyonunu veya anlaşmalı hastaneleri araştırırken üç teknik hata güveni anında zedeler:

1. **Bozuk Sağdan Sola (RTL) Arapça Görünüm:** Otomatik çeviri eklentileri metni çevirir ancak mantıksal boşlukları ve çift yönlü tıbbi terimleri (`<bdi>`) korumaz; bu da kaymalara (`CLS`) yol açar.
2. **Belirsiz Yasal ve Tıbbi Sınırlar:** Koordinasyon rolü ile tıbbi karar sınırlarının net ayrılmaması veya form üzerinden hassas tıbbi dosya toplanması veri güvenliği riski doğurur.
3. **Eksik Çok Dilli Teknik SEO:** Dille özelleştirilmiş statik URL'ler, karşılıklı `hreflang` etiketleri ve yapay zeka botlarına uygun SSR yanıtları olmadan yabancı dil sayfaları dizine eklenmez.

## Derleme Zamanı Çok Dilli Doğrulama Kapısı (`validate-i18n.mjs`)

5 dil, 12 branş ve 3 hukuki rehberi kapsayan (`142 statik sayfa`) bir sağlık platformunda tek bir eksik çeviri anahtarı bile kurumsal güveni sarsar. Bu yüzden `prebuild` aşamasında tüm dillerin anahtar eşleşmesini zorunlu kılıyoruz:

```ts
// scripts/validate-i18n.mjs: Derleme öncesi 5 dilde %100 anahtar eşleşme kontrolü
const LOCALES = ["ar", "en", "fr", "ru", "tr"] as const;
const SERVICE_IDS = [
  "liver-transplantation",
  "kidney-transplantation",
  "oncology",
  "cardiology",
  "neurosurgery",
  "orthopedic-surgery",
] as const;

export function assertLocaleParity(
  baseKeys: Map<string, string>,
  targetLocale: string,
  targetKeys: Map<string, string>
): void {
  for (const [keyPath, expectedType] of baseKeys.entries()) {
    const actualType = targetKeys.get(keyPath);
    if (!actualType) {
      throw new Error(`[i18n-gate] Missing key "${keyPath}" in locale "${targetLocale}"`);
    }
    if (actualType !== expectedType) {
      throw new Error(`[i18n-gate] Type mismatch at "${keyPath}" in "${targetLocale}"`);
    }
  }
}
```

## Canlı Üretim Kanıtı: Healix Medical (İstanbul)
