**الخلاصة التنفيذية:** المريض الدولي وعائلته يبحثون عن تنسيق العلاج في إسطنبول أو الخليج بلغتهم الأم (العربية، الإنجليزية، الفرنسية، الروسية، أو التركية). تفقد معظم شركات التنسيق الطبي عملاءها لصالح منصات الوساطة لأن موقعها إما بطيء بلغة واحدة أو مبني بقالب ووردبريس مترجم آلياً. بناء منصة Next.js 16 ثابتة بدعم عربي RTL أصلي وبوابة فحص ترجمات وقت البناء ونموذج تواصل يحترم الخصوصية الطبية يمنح الشركة أصلاً رقمياً يتصدر بحث جوجل.

## لماذا تفشل قوالب المواقع التقليدية في قطاع التنسيق الطبي الدولي؟

عندما يبحث مريض أو مرافق عن إجراءات زراعة الأعضاء أو الأورام أو المستشفيات المتعاقدة في تركيا، هناك 3 أخطاء تقنية تقتل الثقة فوراً:

1. **تشوّه واجهة اللغة العربية (RTL):** إضافات الترجمة الآلية تقلب النصوص دون ضبط الهوامش المنطقية أو عزل المصطلحات ثنائية الاتجاه (`<bdi>`)، مما يسبب تداخل الكلمات واهتزاز الصفحة (`CLS`).
2. **غياب الحدود القانونية والطبية الواضحة:** خلط التسويق بوعود طبية أو طلب رفع تقارير صحية حساسة عبر نماذج غير مؤمّنة يعرّض الشركة لمخاطر قانونية.
3. **ضعف السيو متعدد اللغات (Multilingual SEO & GEO):** غياب روابط مستقلة لكل لغة وعلامات `hreflang` المتبادلة يمنع جوجل ووكلاء الذكاء الاصطناعي (ChatGPT وPerplexity) من فهرسة الصفحات العربية والفرنسية والروسية.

## بوابة فحص التعدد اللغوي وقت البناء (`validate-i18n.mjs`)

في منصة طبية تغطي 5 لغات و12 تخصصاً و3 أدلة قانونية (`142 صفحة ثابتة`)، أي مفتاح ترجمة ناقص يضر بمصداقية الشركة. لذلك نفحص تطابق جميع المفاتيح آلياً قبل عملية البناء (`prebuild`):

```ts
// scripts/validate-i18n.mjs: فحص تطابق المفاتيح عبر اللغات الخمس قبل البناء
const LOCALES = ["ar", "en", "fr", "ru", "tr"] as const;
const SERVICE_IDS = [
  "liver-transplantation",
  "kidney-transplantation",
  "oncology",
  "cardiology",
  "neurosurgery",
  "orthopedic-surgery",
] as const;

export function assertLocaleParity(
  baseKeys: Map<string, string>,
  targetLocale: string,
  targetKeys: Map<string, string>
): void {
  for (const [keyPath, expectedType] of baseKeys.entries()) {
    const actualType = targetKeys.get(keyPath);
    if (!actualType) {
      throw new Error(`[i18n-gate] Missing key "${keyPath}" in locale "${targetLocale}"`);
    }
    if (actualType !== expectedType) {
      throw new Error(`[i18n-gate] Type mismatch at "${keyPath}" in "${targetLocale}"`);
    }
  }
}
```
