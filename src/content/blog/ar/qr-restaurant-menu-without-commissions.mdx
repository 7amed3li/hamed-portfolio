**الخلاصة:** تخسر المطاعم بين **20% و30%** عمولة على كل طلب عبر تطبيقات التوصيل، أو تنفّر السائحين بملفات PDF بطيئة وصعبة القراءة على الهاتف. استبدال ذلك بمنصة منيو QR مبنية بـ **Next.js 16 وSupabase** يمنح المطعم موقعاً يفتح في أقل من ثانية بـ 10 لغات، مع تحويل عملات لحظي وطلب مباشر عبر واتساب **بعمولة 0%** خلال 1 إلى 3 أسابيع.

## لماذا تخسر المبيعات مع منيو PDF وتطبيقات العمولة؟

عندما يمسح الزبون رمز QR على طاولة مطعم في إسطنبول أو الرياض أو القاهرة، يواجه غالباً أحد خيارين محبطين:

1. **ملف PDF ثقيل (10–20 ميجابايت):** يفتح ببطء على باقة الجوال، ويجبر الزبون على التكبير المستمر بدون بحث أو ترجمة فورية.
2. **تطبيقات التوصيل الوسيطة:** تقتطع **20% إلى 30%** من قيمة كل فاتورة، وتحتفظ ببيانات عملائك لنفسها.

المنصة الرقمية المخصصة تحول رمز الـ QR إلى **أداة مبيعات سريعة مملوكة للمطعم بالكامل**، وتجعله يظهر مباشرةً في نتائج بحث Google المحلي.

### كيف يتم الطلب عبر واتساب بدون عمولة أو تسجيل حساب؟

1. يتصفح العميل المنيو بلغته الأم ويشاهد الأسعار محوّلة تلقائياً لعملته (مثلاً الريال أو الدولار أو الليرة).
2. يختار الأطباق والكميات داخل سلة خفيفة في المتصفح.
3. عند الضغط على **اطلب عبر واتساب**، تتولّد رسالة منظمة تلقائياً بالأصناف والكميات والإجمالي لإرسالها فوراً للمطعم.

```ts
type CartItem = { name: string; qty: number; priceTry: number };

export function buildWhatsAppOrderUrl(phone: string, items: CartItem[], table?: string) {
  const lines = items.map((i) => `• ${i.qty}x ${i.name}: ${i.qty * i.priceTry} TRY`);
  const total = items.reduce((sum, i) => sum + i.qty * i.priceTry, 0);
  const header = table ? `Table #${table} Order:` : "New Direct Order:";
  const text = [header, ...lines, `Total: ${total} TRY`].join("\n");
  return `https://wa.me/${phone}?text=${encodeURIComponent(text)}`;
}
```

### كيف يعدّل صاحب المطعم الأسعار في 5 ثوانٍ؟

عند تغيير سعر أي طبق أو نفاد كمية صنف معين، يدخل المالك إلى لوحة التحكم المرتبطة بـ **Supabase** ويحدّث السعر أو حالة التوفر مرة واحدة، فينعكس التحديث فوراً على جميع اللغات العشر والعملات الست دون كتابة سطر كود واحد.
