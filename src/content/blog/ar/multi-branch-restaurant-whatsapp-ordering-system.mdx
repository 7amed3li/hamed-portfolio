**الخلاصة التنفيذية:** عندما يتوسع المطعم إلى عدة فروع أو يقدّم أكثر من 85 طبقاً يومياً لعملاء محليين وسيّاح، تفشل قوائم الـ QR البسيطة ذات الصفحة الواحدة. يرسل العملاء طلباتهم للفرع الخطأ، وتلتبس ساعات العمل الليلية، وتقتطع تطبيقات التوصيل حتى 30% من كل طلب. بناء منصة Next.js 16 ذكية تربط السلة بالفرع الأقرب وتولّد صفحات ثابتة لكل طبق بـ 5 إلى 10 لغات يحل مشكلة التشغيل وجلب الزوار من جوجل في نظام واحد.

## مشكلتان تشغيليتان تواجهان المطاعم متعددة الفروع والمطاعم عالية الحركة

من واقع بناء منصات إنتاجية لمطاعم حية في إسطنبول، هناك عقبتان رئيسيتان تستنزفان المبيعات:

1. **تداخل طلبات الفروع ومناطق التوصيل:** عندما يعمل المطعم في عدة أحياء (مثل فرع علي بي كوي حتى 04:00 فجراً، وفرع زيتون بورنو، وفرع ساريير)، فإن استقبال الطلبات على رقم واحد يسبب تأخير التحضير وضياع الطلبات الليلية.
2. **غياب الأرشفة المستقلة للأطباق في جوجل:** وضع 85 طبقاً داخل نافذة منبثقة أو ملف PDF يمنع جوجل من فهرسة كل طبق، بينما توليد صفحة ثابتة لكل طبق × كل لغة (`+970 صفحة SSG`) يحوّل المنيو إلى محرك زيارات مجاني من بحث جوجل.

## موجّه طلبات واتساب الذكي حسب الفرع ونطاق التوصيل

من خلال تعريف ساعات عمل كل فرع والأحياء التي يغطيها ورقم واتساب المطبخ الخاص به في هيكل برمجي موحّد، توجّه سلة الموبايل الطلب المفصّل مباشرة للفرع الصحيح:

```ts
// توجيه طلبات المطعم تلقائياً إلى واتساب الفرع المسؤول عن منطقة العميل
export interface RestaurantBranch {
  id: "alibeykoy" | "zeytinburnu" | "sariyer";
  name: string;
  whatsappE164: string;
  closesAtHour: number;
  districts: readonly string[];
}

export function resolveBranchOrderUrl(
  branch: RestaurantBranch,
  items: ReadonlyArray<{ title: string; qty: number; priceTry: number }>,
  deliveryAddress: string
): string {
  const totalTry = items.reduce((sum, item) => sum + item.qty * item.priceTry, 0);
  const lines = [
    `[${branch.name.toUpperCase()} ORDER]`,
    ...items.map((i) => `${i.qty}x ${i.title} (${i.qty * i.priceTry} TRY)`),
    `Total: ${totalTry} TRY`,
    `Address: ${deliveryAddress}`,
  ];
  return `https://wa.me/${branch.whatsappE164}?text=${encodeURIComponent(lines.join("\n"))}`;
}
```
