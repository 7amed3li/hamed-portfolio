## Real-World Engineering: Leading a Team on a Live 2,000+ User Production System

Academic excellence only matters when stress-tested against real users. I joined the university's software development center and was appointed a core member of the Artificial Intelligence and Digital Transformation Organization (*YZDD*).

I served as a **Team Lead** for a development team of 3 engineers, operating as a **Full-Stack Developer** with a relentless focus on code quality and application security:
* **SAST (Static Application Security Testing):** White-box static analysis of the source code to intercept logic vulnerabilities, variable leaks, and insecure dependencies prior to the build pipeline.
* **DAST (Dynamic Application Security Testing):** Black-box runtime penetration testing without code access, simulating realistic attack payloads, intercepting HTTP requests, and probing API endpoints under adversarial conditions.

### The QR Attendance System: Solving Real-World Fraud at Scale

The challenge was never just building an API to log timestamps. The real engineering problem was: **How do you cryptographically prove that a student is physically inside a specific lecture hall and prevent attendance fraud across campus?**

We architected a 3-pillar engineering solution:
1. **Strict Geofencing Verification:** Satellite and browser location coordinates verify that the student is strictly within **50 to 200 meters** of the classroom perimeter.
2. **Dynamic 15-Second Ephemeral QR Tokens:** The QR code displayed on the lecture screen generates short-lived, digitally signed cryptographic tokens that cycle every 15 seconds, rendering screenshot sharing via messaging apps entirely useless.
3. **7-Layer Defense Architecture:** Hardened against token forgery and replay attacks, backed by **Redis in-memory caching** and **Circuit Breakers** to absorb the peak concurrency spikes when hundreds of students scan simultaneously within a 2-minute lecture start window.

Today, the system is in active daily production across Tokat Gaziosmanpaşa University:
* Running across **6 faculties**, **13 academic departments**, and **42 courses**.
* Actively serving over **2,000 daily users**.
* Developed over **15 months**, spanning the entire Software Development Life Cycle (SDLC): architectural design, development, security auditing, CI/CD deployment, and production maintenance.

## Open-Source Cybersecurity Contributions: NodeSecure

I extended my security focus into the global open-source community by contributing to **[NodeSecure](https://github.com/NodeSecure)**, an established security ecosystem used worldwide to audit npm packages and JavaScript runtimes for vulnerabilities and supply-chain attacks.

I had **9 Pull Requests officially reviewed, accepted, and merged upstream**:
* Focused extensively on **Abstract Syntax Tree (AST)** analysis in packages like `js-x-ray` and `scanner`.
* An AST translates source code into a structured data tree that security engines can inspect, enabling automated detection of Server-Side Request Forgery (**SSRF**), insecure pseudo-random generators in cryptographic contexts, and obfuscated payloads before packages are deployed to production.

## Post-Graduation: High Agency & Building Production Platforms

I graduated in June 2026. Due to immediate financial realities, I didn't wait passively for a perfect software engineering offer; I took a job working in a restaurant in Istanbul to meet my obligations.

To an outsider, this might have looked like leaving software engineering behind. But **an engineer's problem-solving mindset never switches off.**

I noticed that the restaurant was using an outdated WordPress site with an inaccessible digital menu, riddled with critical vulnerabilities and missed business opportunities:
* **Severe Security Flaws:** Insecure SSL configurations, exposed SSH endpoints, and unpatched plugins.
* **Heavy Asset Bloat:** Painfully slow load times that alienated international tourists looking for quick menus in Istanbul.
* **Non-existent SEO:** Zero structured data in Taksim/Cihangir, one of the densest tourist districts in Istanbul, forfeiting thousands of potential walk-ins to competitors.

I approached the restaurant owner with commercial metrics and technical diagnosis. Naturally, abstract tech debt is hard to visualize, so he challenged me:  
> **"Build a prototype and let's see what you can do."**

Instead of endless debate, I built a blistering-fast, interactive prototype. The moment he experienced the speed, UI, and live currency conversions, hesitation turned into complete confidence.

I engineered and deployed the full production platform from scratch:
* Built on **Next.js 16 (App Router), React 19, and Supabase**.
* Implemented **10 dynamic languages** and a **live currency converter supporting 6 currencies** with real-time exchange rate APIs.
* Built localized **direct WhatsApp ordering** and automated message templating.
* Executed a flawless WordPress migration with **25+ permanent 301 redirects** and comprehensive **Schema.org Local SEO**.
