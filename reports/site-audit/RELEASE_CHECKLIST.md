## 2. إجراءات النشر على الإنتاج (Production Deployment Procedure)

> [!IMPORTANT]
> النشر الفعلي على الإنتاج يتطلب موافقة المالك الصريحة ولا يتم تلقائياً.

### خطوات النشر الموصى بها:
1. مراجعة التغييرات عبر `git diff` للتأكد من عدم وجود ملفات مؤقتة أو مفاتيح سرية.
2. دمج التعديلات إلى فرع `main`.
3. دفع التغييرات إلى المستودع البعيد:
   ```bash
   git push origin main
   ```
4. يطلق Vercel عملية البناء التلقائية `velite && next build`.

## 3. فحوصات ما بعد النشر (Post-Deployment Smoke Tests)

عند اكتمال النشر على الخادم المباشر، يجب تنفيذ الفحوصات التالية:
1. **فحص الروابط الرئيسية:**
   - `https://www.hamedmohamed.dev/en`
   - `https://www.hamedmohamed.dev/ar`
   - `https://www.hamedmohamed.dev/tr`
2. **فحص خريطة الموقع:**
   - طلب `https://www.hamedmohamed.dev/sitemap.xml` والتحقق من احتوائها على جميع الصفحات بالبادئة `www.`.
3. **فحص أدوات مشرفي المواقع (Google Search Console):**
   - تقديم الـ sitemap الجديد في GSC.
   - التحقق من بدء فهرسة صفحات الخدمات العربية والتركية التي رُفع عنها الحظر.
4. **فحص التجاوب الحي على الهواتف الذكية:**
   - تجربة قائمة الموبايل باللمس وعلى أجهزة حقيقية (iOS Safari و Android Chrome).
   - تجربة تمرير كتل الأكواد في المدونة.
